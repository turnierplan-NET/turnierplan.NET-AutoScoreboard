# turnierplan.NET | AutoScoreboard

*Always display the fullscreen page of the tournament which is currently playing*

## Introduction

This repository contains a .NET console application with a single Razor page. When this page is opened in a browser, it will always show the currently active tournament in a specific **turnierplan.NET** folder. At some point, this functionality might be integrated into the main application natively. See the [issue in the main repo](https://github.com/turnierplan-NET/turnierplan.NET/issues/307) for more information.
